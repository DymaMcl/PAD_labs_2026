Fiecare laborator este dezvoltat pe un branch separat:

| Branch        | Laborator                                   |
|---------------|---------------------------------------------|
| [`laborator_1`](https://github.com/DymaMcl/PAD_labs_2026/tree/laborator_1/laborator_1) | Comunicare fiabilă și mesagerie (producer → broker → consumer) |
| [`laborator_2`](https://github.com/DymaMcl/PAD_labs_2026/tree/laborator_2/laborator_2) | RPC, contracte și integrare (serviciu gRPC de conturi) |

## Interfața web (Rust)

Pe branch-urile `laborator_1` și `laborator_2`, folderul `interfata_rust` conține un panou de control web scris în Rust (`cd interfata_rust && cargo run --release`, apoi `http://localhost:8080/`).
